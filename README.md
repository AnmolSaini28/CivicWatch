Project Description:
CivicWatch is a web application that helps people report common problems in their area, such as damaged roads, garbage, broken streetlights, and water leakage. Users can report issues anonymously or create an account to track their complaints. They can also view reported issues and check their current status. The platform includes a dashboard for managing complaints and helps administrators keep track of reported problems. We are building CivicWatch using React, Node.js, Express.js, and PostgreSQL, with the aim of making civic complaint reporting easier and more organized.

github repo link: https://github.com/AnmolSaini28/CivicWatch

Functionalities Implemented (Frontend)
Home page with total, pending and resolved issue counts
Dashboard with status counts, most reported problems and recent reports
Track page to check a report’s status using its tracking ID
Sign up with name, email, mobile number, gender and password
Form validation on Sign up (10-digit mobile number, password of at least 8 characters, matching passwords, no duplicate email or mobile)
Login with email and password, and an error message for wrong details
Logout, and the navbar shows the user’s name after login
